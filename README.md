# Air Brake Trainer

A freight train air brake simulator that runs entirely in your web browser: a brake pipe propagation simulator for the whole train, and a locomotive and car air rack showing the 26L brake valve, MU piping, relay valves and a car's brake system.

Open it at **https://wlohrbach.github.io/air-brake-trainer/**. Nothing is installed and nothing is saved; the first load downloads about 10 MB.

This repository holds only the built web pages. Please send feedback to Will Lohrbach.
